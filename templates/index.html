Project Objective

The objective of this project is to predict whether a student will be placed or not using machine learning techniques based on academic performance and skills.

Problem Statement

Every year, thousands of students graduate from universities, but securing a job remains a challenge due to varying skill sets and academic records. Companies struggle to efficiently screen candidates, while students often lack clarity on which specific metrics impact their placement chances the most.

Can we accurately predict placement outcomes to help students improve their profiles?

Current Challenges

Manual Prediction

HR departments rely on manual resume screening, which is slow and prone to human error.

Low Accuracy

Traditional heuristic methods lack the precision to identify complex patterns in student data.

Lack of Automation

Real-time feedback for students on their employability is rarely available in current systems.

Scalability

As the number of applicants grows, traditional systems fail to scale effectively.

Proposed Solution

We propose a Binary Classification System powered by Machine Learning.

Data Cleaning Pipeline

Null Value Check

Scanned dataset for missing values. Rows with critical missing data (CGPA, Skills) were imputed using mean strategy.

Duplicate Removal

Identified and removed 15 duplicate student entries to prevent data leakage and bias.

Outlier Handling

Used IQR method to detect extreme outliers in 'Aptitude Score' and capped them to the 95th percentile.

Useless Column Removal

Dropped irrelevant columns like 'Student ID' and 'Name' that do not impact placement probability.

Data Preprocessing

Label Encoding

Converted categorical text data (like 'Yes/No' for Internships) into numerical labels (1/0).

Feature Scaling

Normalized features to a 0-1 range using MinMaxScaler to ensure model convergence.

Train-Test Split

Split data into 80% Training and 20% Testing sets to validate model performance.

One Hot Encoding

Applied to nominal features (like Branch) to create binary columns for each category.

Model Training

Logistic Regression

A linear model best suited for binary classification problems. Provides probabilities for outcomes.

Decision Tree

Non-linear model that splits data based on feature values. Easy to interpret but prone to overfitting.

Random Forest

Ensemble learning method operating by constructing a multitude of decision trees. High accuracy.

Conclusion

This project successfully demonstrates the application of Machine Learning in solving real-world educational problems. By analyzing historical data, we can predict placement outcomes with an accuracy of 87.8%.
