<h1 align="center">🎓 Placement ML Project</h1>

<p align="center">
  <b>Predicting Student Placements using Machine Learning 🚀</b>
</p>

<hr>

<h2>📌 Overview</h2>
<p>
This project uses Machine Learning algorithms to predict student placement outcomes 
based on academic and profile data. It helps identify key factors that influence hiring success.
</p>

<h2>⚙️ Tech Stack</h2>
<ul>
  <li>🐍 Python</li>
  <li>📊 Pandas, NumPy</li>
  <li>🤖 Scikit-learn</li>
  <li>📈 Matplotlib, Seaborn</li>
</ul>

<h2>🔍 Features</h2>
<ul>
  <li>✔️ Data Preprocessing</li>
  <li>✔️ Exploratory Data Analysis (EDA)</li>
  <li>✔️ Feature Engineering</li>
  <li>✔️ Multiple ML Models</li>
  <li>✔️ Model Evaluation</li>
</ul>

<h2>📊 Models Used</h2>
<p>
🔹 Logistic Regression <br>
🔹 Decision Tree <br>
🔹 Random Forest
</p>

<h2>🎯 Objective</h2>
<p>
To build an accurate model that predicts student placement and provides insights 
into the most important influencing factors.
</p>

<h2>🚀 How to Run</h2>

<pre>
git clone https://github.com/Shubhampandey7079/placement_ml_project.git

</pre>
